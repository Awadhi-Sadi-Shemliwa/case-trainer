# Claude API usage: the owner's budget rules (2026-11-16)

Account: $5 of credit, Tier 1 (roughly 30-40k input tokens per minute). The bottleneck is tokens per minute, not the
budget. Every rule below is enforced in code; `app/lib/grading/claude_client.dart` is the only place that calls the API.

| Owner rule | How the app meets it |
|---|---|
| Claude writes text; the app renders the PDF locally | Claude returns small JSON (verdicts, a summary). `app/lib/report/case_report.dart` renders the PDF on the phone with the `pdf` package. No HTML or PDF code is ever generated by Claude. |
| Haiku 5.5 for fast, cheap tasks (summaries, formatting) | `summaryModel = claude-haiku-5-5`: the end-of-case summary page (effort low, max 2000 tokens) and Settings' "Test the connection" (max 300). |
| Sonnet 5.5 only for real reasoning | `graderModel = claude-sonnet-5-5`: grading a written answer (effort medium, max 8000 tokens, server-side refusal fallback). |
| Send only the data needed, not the whole database | Grading sends one step: its text, a chart description sampled to at most 24 points per series, the model answer, the rubric and only the pipeline numbers that step uses. The summary sends one line per step (best score, missing point labels, at most two quoted errors cut to 160 characters), no reading steps. |
| Retry automatically instead of failing | 429 / 5xx / dropped connections: wait `retry-after` (capped at 10 s) or 2 s then 4 s, at most two retries. Credit, key and other 4xx errors are never retried. If it still fails, the answer is kept and "Grade now" retries; no try is used up. |
| Don't flood the API in the same second | All calls go through one app-wide queue: one request at a time. |
| Prompt caching for repeated material | The step material is the first content block with `cache_control: ephemeral`; the answer is a separate last block. A second or third try on the same step within five minutes reads the material from the cache. |
| Watch the spend | Each verdict stores its usage (tokens, cache reads, retries, time, estimated cost). Settings, Examiner shows "N answers graded, about $X used". |

## Measured (2026-11-16, PC, the owner's real P34 step-9 answer, `LIVE_CLAUDE=1 flutter test test/live_examiner_test.dart`)
| Call | Model | Input | Cache write | Cache read | Output | Time | Cost |
|---|---|---|---|---|---|---|---|
| Grade, try 1 | Sonnet 5.5 | 206 | 3,915 | 0 | 1,048 | 9.3 s | $0.021 |
| Grade, try 2 (same step) | Sonnet 5.5 | 206 | 0 | 3,915 | 966 | 7.6 s | $0.010 |

So $5 is roughly 250-500 graded answers. The same answer scored 25 and 32.5 on two tries: the examiner's judgement
varies a little between calls, while the quoted errors were the same both times. Prompt 7 (calibration) measures this.
